# Surya Vikas – Portfolio Website

This repository contains the source code for my personal portfolio website.  
It showcases my projects, skills, experience, and certifications, along with a contact section for collaboration and opportunities.

## 🌐 Live Website
🔗 https://suryavikas-portfolio.onrender.com  
(Replace with your final production URL if needed)

---

## 🚀 Features

- Modern, responsive UI built with React and Tailwind CSS
- Smooth animations using Framer Motion
- Filterable project showcase
- Skills, education, and certifications sections
- Contact form powered by EmailJS
- Dark mode support
- Fully responsive across devices

---

## 🛠 Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS, shadcn/ui
- **Animations:** Framer Motion
- **Forms & Email:** EmailJS
- **Version Control:** Git & GitHub

---

## 📦 Getting Started (Local Setup)

### Prerequisites
Make sure you have the following installed:
- Node.js (v18 or later)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/surya-vikas/surya_vikas_portfolio.git

# Navigate to the project directory
cd surya_vikas_portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
